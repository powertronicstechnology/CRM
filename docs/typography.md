# CRM typography

Use Nunito Sans for headings, body and controls. Weight 400 for ordinary text, 500 for secondary emphasis and 600 for headings and important values. Avoid extra-bold/black weights.

- 13px: badges and compact metadata (minimum text size).
- 14px: field labels, navigation and compact controls.
- 16px: body content, customer-detail values, inputs and amounts.
- 16px: customer-card names (semibold), with 14px supporting details.
- 14px: activity descriptions; 13px timestamps and author names.
- 18px: section counts and smaller modal headings.
- 20px: page/dialog titles.
- 24px: dashboard KPI totals only.

Keep numeric columns aligned with tabular numerals. Customer-card currency uses full Indian rupee formatting consistently. Green represents received/settled amounts; muted amber represents outstanding balances. Keep rounded cards and their stable heights.

Customer grid cards: stable 350px height, 4px amber accent. Activity uses compact divided rows instead of nested large cards. Keep dashboard KPI numerals at 24px; do not apply one font size globally.
